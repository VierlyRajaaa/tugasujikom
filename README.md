Ketika user membuka index.php, PHP akan mengambil isi file header.php, lalu menampilkan bagian Hero, kemudian menutupnya dengan isi file footer.php.

Ketika user membuka menu.php, PHP akan mengambil data makanan dari data-menu.php, mengambil tampilan atas dari header.php, membuat perulangan kartu produk, dan menutupnya dengan footer.php.
